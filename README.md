# 📊 DecodeLabs Data Analytics Internship

Welcome to my Data Analytics Internship repository, where I document projects completed during the DecodeLabs Internship. This repository showcases my journey in developing practical data analytics skills through real-world datasets, business problem-solving and hands-on analysis.

---

## 🚀 About the Internship

The DecodeLabs Data Analytics Internship is designed to simulate the responsibilities of a professional Data Analyst by focusing on:

- Data Cleaning & Preparation
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Intelligence
- Statistical Analysis
- Analytical Thinking
- Reporting & Insight Generation

Each project builds upon the previous one to develop a complete data analytics workflow.

---

## 📂 Projects

### 🧹 Project 1 – Data Cleaning & Preparation
**Objective:** Transform raw data into a clean and reliable dataset.

#### Tasks Completed
- Identified and handled missing values
- Verified and removed duplicate records
- Standardized date and numerical formats
- Performed data quality checks
- Prepared the dataset for analysis

#### Skills Demonstrated
- Data Cleaning
- Data Validation
- Excel Data Preparation
- Data Quality Assurance

---

### 📈 Project 2 – Exploratory Data Analysis (EDA)
**Objective:** Discover patterns, trends, and insights from business data.

#### Tasks Completed
- Calculated descriptive statistics
- Analyzed revenue performance
- Examined product performance
- Evaluated customer payment preferences
- Identified outliers and unusual transactions
- Created Pivot Tables and visualizations

#### Key Findings
- Generated over **1.26 million** in total revenue
- Analyzed **1,200 transactions**
- Identified top-performing products
- Discovered monthly sales trends
- Evaluated customer payment behavior

#### Skills Demonstrated
- Exploratory Data Analysis (EDA)
- Pivot Tables
- Data Visualization
- Statistical Analysis
- Business Insight Generation
